The kitchen as an interaction graph

Every tracked agent — each worker and the robot — becomes a node; who-affects-whom becomes an edge. This is the structure the predictor reasons over.

Read it top-to-bottom. In the scene, each worker (boxes 1–3) and the robot (R) is detected and placed on the shared floor; the colored dotted line carries each one down to its node. Below, the nodes form a graph: dashed edges link workers who are close enough to affect each other, and the arrows show every worker feeding into the robot's decision — the robot predicts each worker's next 1.6 s and plans around all of them at once. Modeling the scene as this agent graph (after Trajectron++, Salzmann et al. 2020) is what lets one predictor handle a variable number of people.
