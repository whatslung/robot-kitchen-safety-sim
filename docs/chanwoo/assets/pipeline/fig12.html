Multimodal prediction → why the robot yields

The robot tracks every worker and predicts each one's next moves. It acts only when a predicted path will enter its stop ring.

multimodal futures (per worker) most-likely predicted path robot tracks worker stop ring slow ring

Why this becomes avoidance. The robot predicts a fan of likely next moves for every worker (colored arrows), not a single guess. Workers 2–4 have no mode heading into the robot, so nothing happens. Worker 1's most-likely path (pink dashed) curves toward the robot and would cross into the stop ring within the 1.6 s horizon (red burst) — that specific event is the trigger, so the robot slows/retreats before Worker 1 arrives. Modeling each agent's multiple futures is after Trajectron++ (Salzmann et al., 2020).
