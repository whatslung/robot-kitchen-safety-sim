Trajectory predictor: encoder–decoder with a multimodal head

Observed motion is encoded (LSTM or Transformer — interchangeable), then a shared head emits K = 3 possible futures, each weighted and with per-step uncertainty.

One predictor, two interchangeable encoders. The observed 8-step track is normalized to the worker's own frame, then encoded by either an LSTM (final hidden state) or a Transformer (last token as "now") — both produce the same 64-d context, so the rest of the network is shared. A small multimodal head then outputs K = 3 future paths at once (12 steps each), each with a weight and a per-step uncertainty σ. Trained best-of-K (only the closest mode is regressed) so the three modes stay distinct instead of averaging into one blurred guess. Code: trajectory/learned_predictor.py.
