Principle: same floor position = same person. A nadir (straight-down) camera makes the image ≈ the floor plane, so a one-time affine fit turns each detection's pixel into a floor coordinate (X, Z), calibrated to a 5 cm residual. Every camera then speaks one coordinate system, so the same person from different views lands on the same spot and is merged (within 0.4 m). A single world-space tracker (Kalman + nearest-neighbour matching + short coast for briefly-missed frames) links these into one continuous track with velocity — filling gaps and smoothing position. Measured effect: coverage recall 0.924 → 0.940 (nadir-zone-fusion §5-9).
