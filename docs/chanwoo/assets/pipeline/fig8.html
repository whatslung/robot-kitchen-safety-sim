The payoff: prediction turns a collision into a head start

Same scene, same worker path, same robot — the only difference is whether the predictor is on.

WITHOUT prediction
Arm sweeps into the worker
The robot never anticipates the approach; it keeps working and the arm makes contact — an emergency stop fires only after the hit.
outcome: E-STOP on contact (wrist) · person–robot 1.48 m (inside stop ring)
WITH prediction
Robot slows 1.6 s early, worker safe
The predicted path (red dashes) is seen entering the stop ring 1.6 s ahead, so the robot pre-emptively slows and backs off before contact.
outcome: pre-emptive slow, no contact · keeps 3.90 m separation

This is what the whole pipeline buys. Detection → world fusion → tracking feed a 1.6 s trajectory prediction; when that predicted path is about to enter the stop ring, the robot acts before the person arrives instead of reacting to a contact. Presentation demo — transfer speeds are exaggerated for visibility; the ISO/TS 15066 safety decision is unchanged.
