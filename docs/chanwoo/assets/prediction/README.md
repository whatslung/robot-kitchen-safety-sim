# 예측 밀도 구름 — 나디르(탑뷰) 동선 그림

학습형 예측기(LSTM·Transformer)가 낸 **멀티모달 밀도 구름**을 수직 나디르 시점에서
찍은 발표용 그림. 후드·덕트·천장 배관은 뺐고(탑뷰에서 시야를 막는다), 조리원은 **실제 3D
캐릭터**(위생복·보행 자세, 진행 방향을 향함)로 보인다. 흰 곡선은 조리원의 **실제 이동
동선**, 색 구름·색 곡선은 그 시점에서 백엔드 `/predict`가 돌려준 K=3 모드의 미래 예측이다.

- 좌표·안전링(초록 감속 3.9 m · 주황 정지 3.1 m · 빨강 팔 반경 1.87 m)은 모두 씬의 실측 미터.
- 구름이 진행 방향으로 **길고 가로로 좁은 띠**(방향 확실, 속도 불확실)로 갈라지는 것이 요지다 —
  등방 원이 아니라 방향성이 있어야 "어디로 갈지"를 말한다.

## 그림 읽는 법 (범례)

한 컷에는 성질이 다른 선·면이 겹쳐 있다. 구분해서 읽어야 한다.

### 흰 곡선 — 과거 동선 (관측)
조리원이 **이미 걸어온 경로**다. 예측이 아니라 관측된 과거로, "이 사람이 어디서 왔나"를 보여준다.
곡선의 **앞 끝(사람 위치)**이 예측이 시작되는 '현재'다.

### 색 곡선 + 같은 색 구름 — 미래 예측 (K=3 모드)
백엔드 `/predict`가 돌려준 **3가지 미래 가설**이다. 색은 **위험도가 아니라 확률(가중치) 순서**다 —
모드는 가중치 내림차순으로 정렬돼 나오므로 **teal이 항상 모델이 가장 유력하다고 본 경로**다.
색 **곡선**은 각 모드의 미래 경로, 같은 색 **구름**은 그 경로 주변의 **불확실성(σ)** 이다.

| 색 | 모드 | 뜻 | 선 두께 |
|---|---|---|---|
| 🟢 teal `#2dd4bf`  | mode 0 | **최빈(가장 유력)** 미래 경로 | 가장 굵게 |
| 🔵 blue `#60a5fa`  | mode 1 | 두 번째 유력 | 얇게 |
| 🩷 pink `#f472b6`  | mode 2 | 세 번째 유력 | 얇게 |

- 세 색이 **고르게 갈라지면** 방향이 불확실(예: `lstm_move_01` = 0.43 / 0.40 / 0.17).
- 한 색이 **진하고 굵으면** 그쪽이 유력(예: `tf_move_02` = 0.61 / 0.21 / 0.19 — Transformer가 더 확신).
- 시간 지평선은 현재부터 **3.5 s**(모델 출력 12스텝 × 0.4 s)까지다.

### 원 3개 — 로봇 안전링 (예측과 무관)
예측선이 아니라 로봇 기준 반경이다. 🟢 감속 3.9 m · 🟠 정지 3.1 m · 🔴 팔 반경 1.87 m(실측 미터).

| 파일 | 모델 | 동선 진행 |
|---|---|---|
| `lstm_move_01`~`05.png` | LSTM (`chanubc/human-move-lstm`) | 곡선 초입 → 로봇 셀 접근까지 5컷 |
| `tf_move_01`~`03.png` | Transformer (`chanubc/human-move-transformer`) | 같은 동선 중간 3컷 |

재현: 백엔드를 띄우고(Transformer는 `PREDICT_NET=transformer`) 조리원을 곡선으로 걷게 한 뒤
나디르 카메라로 캡처했다. 실행법은 [최상위 README](../../../../README.md#검출예측-파이프라인-백엔드) 참조.
