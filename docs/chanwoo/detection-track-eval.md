# detector-track E2E 예측 평가 (감사 P0-2)

> 생성 2026-08-24 · 설계 [specs/2026-08-24-detection-track-eval-design.md](specs/2026-08-24-detection-track-eval-design.md)
> 재현: `uv run --group serve python train/eval_traj_dettrack.py --split test`
> 결과 원본: [results/detection-track-eval.json](results/detection-track-eval.json)

실사 오버헤드 사람 클립에서 **GT 라벨 트랙**과 **실제 검출 트랙(YOLO+ByteTrack)**을
같은 윈도우(관측 8 × 0.4s → 예측 12 × 0.4s)로 CV·칼만·LSTM에 돌려, 검출 노이즈가
궤적 예측·안전 결정에 주는 타격을 측정한다.

## 데이터·가정 (반드시 함께 읽을 것)

- **데이터**: `dataset/overhead-person-v3` (Roboflow `riccardo-kxtut/overhead-person`, CC BY 4.0),
  test split — 클립 5개(cam_1·2·3·5·6), 프레임 137. **일반 오버헤드 사람** 클립으로,
  P0-2 완료 조건의 "주방/조리실 유사"는 아니다(현 워크트리 최선의 실사 데이터). 주방 클립
  확보 시 같은 파이프라인으로 재실행.
- **검출기**: `training/island_yolo11s/weights/best.pt` — **우리 시뮬(섬 배치 나디르)로 학습**한
  YOLO11s. 이 실사 데이터는 학습 분포 밖(sim-to-real 격차) → 아래 낮은 커버리지의 원인.
- **가정(설계 §5)**: 프레임 가로 = 6.0m(셀 가로 ~6.1m), 0.4s/frame, 가상 로봇 = 클립별 GT
  통행 중심, 정지반경 1.2m·감속반경 2.0m·지평선 1.6s. GT↔검출 매칭 중심거리 임계 0.08(정규화).
- **해석 원칙**: 절대 위험진입 시각은 위 가정에 의존한다. **핵심 신호는 GT-예측 vs 검출-예측의
  *차이*** — 같은 가상 로봇·같은 스케일을 두 경로에 똑같이 적용하므로 이 차이는 가정과 무관.

## 헤드라인 — 병목은 per-track 지터가 아니라 **검출 커버리지**

- **GT 트랙 66개 · GT 윈도우 287개** 중 **검출 입력이 성립한 윈도우는 87개(30%)뿐**.
  미검출 프레임 733 · fragmentation 14 · ID switch 1. → 사람의 약 70%가 이 검출기로는
  아예 예측 대상이 못 된다(관측 창을 채우지 못함). **검출 실패의 지배 성분은 miss(recall)**이고,
  fragmentation·ID switch는 소수다.
- **검출이 성립하면** 검출 노이즈가 예측에 주는 추가 오차는 작다(아래 공정 비교).
- 즉 이 검출기의 sim-to-real 위험은 "트랙이 흔들려서"가 아니라 **"사람을 못 봐서"** 생긴다.

## 공정 비교 — 검출이 성립한 같은 87개 윈도우 (ADE/FDE, m)

| 예측기 | 입력 | ADE | FDE | ADE(움직인 것) | FDE(움직인 것) |
|---|---|---|---|---|---|
| CV | GT-예측 | 0.328 | 0.584 | 0.282 | 0.491 |
| CV | 검출-예측 | 0.333 | 0.522 | 0.310 | 0.477 |
| Kalman | GT-예측 | 0.454 | 0.834 | 0.428 | 0.785 |
| Kalman | 검출-예측 | 0.432 | 0.710 | 0.412 | 0.671 |
| LSTM | GT-예측 | 0.618 | 1.004 | 0.623 | 0.993 |
| LSTM | 검출-예측 | 0.724 | 1.137 | 0.732 | 1.136 |

- CV·칼만은 GT-예측과 검출-예측이 사실상 동급(검출-예측 FDE가 오히려 소폭 낮은 건 결측
  hold-last 평활 효과 + 이 부분모집단이 상대적으로 쉬운 트랙이기 때문).
- LSTM은 검출 입력에서 ADE 0.618→0.724(+17%)로 가장 민감. LSTM이 시뮬 좌표로 학습돼
  실사 스케일·움직임 분포에서 이미 불리(참고표에서도 GT 입력조차 CV보다 나쁨).

**참고 — 예측 상한(전체 GT 윈도우 287, 검출 무관)**: CV ADE 0.239 / FDE 0.432 · Kalman 0.278 / 0.510 ·
LSTM 0.613 / 1.051. (검출 성립 부분모집단 87개가 전체보다 약간 어려운 트랙임을 보여줌.)

## 실패모드별 검출-예측 (ADE/FDE, m)

| 예측기 | clean (n=10) | degraded: miss/switch/frag (n=77) |
|---|---|---|
| CV | 0.150 / 0.182 | 0.357 / 0.566 |
| Kalman | 0.173 / 0.234 | 0.465 / 0.772 |
| LSTM | 0.499 / 0.886 | 0.753 / 1.169 |

- 검출 결함이 없는 윈도우(clean)에선 예측이 매우 정확(CV ADE 0.150). 결함이 낀 윈도우
  (degraded)에서 ADE가 **약 2.0~2.4배**로 뛴다 → 잔존 검출 결함이 예측 오차의 주 동인.

## 가상 로봇 위험진입 — GT-예측 vs 검출-예측 (정지반경 1.2m)

| 예측기 | GT 진입 | 검출 진입 | 검출이 놓침(FN) | 검출 헛경보(FP) | 평균 \|Δ진입시각\| |
|---|---|---|---|---|---|
| CV | 58 | 58 | 0 | 0 | 0.000s |
| Kalman | 70 | 70 | 0 | 0 | 0.017s |
| LSTM | 68 | 70 | 0 | 2 | 0.029s |

- **검출이 성립한 윈도우 안에서는** 검출 노이즈가 안전 결정(정지 진입 여부·시각)을 거의
  바꾸지 않는다(Δ ≤ 0.03s, 놓침 0). LSTM만 2건 헛경보.
- ⚠️ 단, 이는 "검출이 성립한" 87개 한정이다. 나머지 200개(검출 실패)는 **로봇이 사람을
  아예 못 보는** 경우로, 위험진입 자체가 계산 불가 = 실제 현장에서 가장 위험한 미탐 구간.

## 결론 / 후속

1. 이 검출기(시뮬 학습)의 실사 성능 병목은 **recall(커버리지)** — per-track 정밀도가 아니다.
   → P0 후속: 실사·실사+시뮬 검출기(`training/real_sim`)로 같은 평가 재실행해 커버리지 개선폭 측정.
2. 검출이 성립하면 CV·칼만은 검출 노이즈에 강건, LSTM은 민감(sim-to-real 좌표 격차).
   → LSTM은 P0-1(독립 test split) 이후 실사 미세조정/스케일 정합을 검토.
3. 위험진입 결정은 커버리지가 확보된 구간에선 검출 노이즈에 강건 — 안전 관점의 진짜 리스크는
   **미탐 구간**이며, 이는 P0-3(라이브 안전 성능: missed entry 등, 시뮬 seed)에서 정면으로 다룬다.
4. **한계**: 데이터가 주방 특정이 아니고, 위험진입은 가상 로봇 가정 기반(절대값 해석 주의).
   train split(4120프레임)로 확대 시 표본↑ — `--split train`.
