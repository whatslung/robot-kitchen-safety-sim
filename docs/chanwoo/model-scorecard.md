# 모델 성적표 — 검출·예측 before/after

> 두 인공지능의 "기존 대비 개선"을 한 장으로. 상세·재현은 각 절 끝 출처 문서.
> 사슬에서의 위치: `CCTV → **검출(YOLO)** → 추적 → 좌표 → **예측(LSTM)** → 안전판정 → 로봇`

**before의 성격이 두 모델에서 다르다** — 표를 읽기 전에 이걸 먼저.

| 모델 | before가 뜻하는 것 | after |
|---|---|---|
| YOLO (검출) | 남이 만든 **기성품**(stock, COCO 사전학습) | 우리 시뮬로 **재학습**(파인튜닝) |
| LSTM (예측) | 학습형을 안 쓰던 **옛 단순 방법**(등속·칼만) | 우리가 새로 **학습**한 예측기 |

YOLO는 기성품이 출발점이라 "원본 → 우리"가 성립한다. **LSTM은 기성품이 없다** — 이 문제 전용이라
처음부터 학습했고, before에 해당하는 건 학습형을 쓰기 전의 단순 규칙이다.

## 1. 검출 · YOLO11s — 사람을 "지금" 찾기

`person` 기준. after는 최신(섬 배치).

| 단계 | Recall ↑ | Precision ↑ | mAP50 ↑ |
|---|---|---|---|
| **before** · stock yolo11s | 0.175 | 0.374 | 0.212 |
| 우리 · 조리셀 배치 | 0.688 | 0.797 | 0.747 |
| **after** · 섬 배치(최신) | **0.871** | **0.872** | **0.874** |

**개선**: Recall ×5.0 · Precision ×2.3 · mAP50 ×4.1. 전 클래스 mAP50 0.931.

> ⚠️ **이 점수는 시뮬 안에서만이다.** 학습에 쓴 것과 같은 종류의 합성 그림으로 잰 값이라 높다.
> 같은 모델을 실제 CCTV에 쓰면 person **recall 0.270 / precision 0.072**(mAP50 0.048)로 무너진다 — 실사엔 못 쓴다.
> 실사가 필요하면 RF-DETR(0.411)·증류 모델(0.491). 근거: `detection-eval.md` §2, §5-7.

출처: `docs/chanwoo/detection-eval.md` §1(원본 vs 우리·조리셀) · §6(섬 재학습)

## 2. 예측 · human-move-lstm — 앞으로 갈 곳 맞히기

관측 8스텝(3.2s) → 예측 12스텝(4.8s), 합성 궤적 val 기준. 등속·칼만과 동일 윈도우.

### 2-1. 위치 정확도 — ADE / FDE (낮을수록 좋음 ↓)

| 방법 | ADE(m) ↓ | FDE(m) ↓ |
|---|---|---|
| **before** · 등속(const-vel) | 1.114 | 2.129 |
| **before** · 칼만(Kalman) | 1.031 | 2.069 |
| **after** · LSTM(최빈 모드) | **0.748** | **1.420** |
| _참고_ · LSTM(minADE@3) | _0.432_ | _0.797_ |
| _참고_ · 스테이션(목표 앎) | _0.694_ | _1.233_ |

**개선**: ADE 칼만 대비 −27% (등속 대비 −33%). 목표를 **모르는** 학습형이 목표를 아는
스테이션 규칙(0.694)에 근접 — PR #3에서 동선에 학습할 구조를 넣은 효과.

- **ADE**: 12스텝 예측 위치오차 평균(m). **FDE**: 12스텝째(4.8s 뒤) 최종 위치오차(m).
- **최빈 모드**: 3갈래 중 확률 최상위 하나 — 단봉 방법과의 공정 비교값.

### 2-2. 안전 recall — 정지반경(R=3.1m) 진입 예측 (높을수록 좋음 ↑)

"지금 반경 **밖**에 있는 사람이 4.8s 안에 반경 **안**으로 들어올지"를 미리 맞혔나.

> ⚠️ **지평선 주의**: 아래 recall은 **오프라인 4.8s 지평선·val 스플릿** 값이다. 실제 로봇은
> `sim.html`의 **1.6s** 지평선으로 판정하며, 짧게 보므로 라이브 recall은 이보다 낮다. 발표에서
> 안전 성능을 말할 땐 1.6s 값을 쓴다(1.6s vs 4.8s 비교표: `prediction-safety-eval.md`).

| 방법 | recall ↑ | precision ↑ |
|---|---|---|
| **before** · 예측 없음(반응형) | 0.000 | — |
| **before** · 등속 | 0.164 | 0.883 |
| **before** · 칼만 | 0.248 | 0.911 |
| **after** · LSTM(최빈 모드) | **0.433** | 0.707 |
| **after** · LSTM(전 모드 합집합) | **0.756** | 0.442 |

**개선**: 칼만 대비 recall ×1.7. **예측이 없으면 recall = 0** — 사람이 반경에 들어온 뒤에야
알아채기 때문(지금 밖이라 진입을 못 봄). 예측기의 값어치가 여기서 드러난다. 전 모드 합집합은
여러 갈래를 다 경계해 recall이 가장 높다(헛정지 늘어남 → 운영점 τ로 조절). 이 recall이
PR #1의 선제 회피(hold)를 쓸 수 있게 하는 재료다.

## 한눈 요약

| | before | after | 대표 개선 |
|---|---|---|---|
| **검출** person recall | 0.175 (stock) | 0.871 (우리·섬) | ×5.0 |
| **예측** 위치오차 ADE | 1.031 (칼만) | 0.748 (LSTM) | −27% |
| **예측** 안전 recall | 0.248 (칼만) | 0.433 (LSTM) | ×1.7 |

- 검출: 못 쓰던 기성품(0.175)을 재학습으로 실용 수준(0.871)까지. **단 시뮬 한정.**
- 예측: 옛 단순법보다 위치는 더 정확하고 위험은 더 일찍 잡는다. 목표를 몰라도 목표 아는 규칙에 근접.
