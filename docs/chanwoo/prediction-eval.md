## 읽는 법

- 값은 `point [lo, hi]` = scene 단위 bootstrap 95% CI. 겹치면 차이가 유의하지 않을 수 있다.
- **움직임** 열 = 예측 구간이 실제로 움직인 윈도우만(정지·지터 제외, 진짜 난이도).
- 스테이션(goal)=현재 목표를 아는 상한 · minADE@K=K모드 중 최선(멀티모달 상한, 오라클).
- **LSTM vs Transformer**: 백본만 다르고 나머지 동일 → 차이는 백본에서 온다.
- **안전 기준**: 단일 'ADE<X' 임계는 없다. 로봇 속도·제동·ISO 여유마진에 달림. 실무 기준은
  1.6s FDE가 정지반경(공칭 1.2m)·마진보다 충분히 작을 것(대략 ≲0.3~0.5m) + 진입 recall↑.
- test 는 val 선택을 고정한 뒤 1회만 평가(운영점 과적합 방지 — 감사 P0-1).
