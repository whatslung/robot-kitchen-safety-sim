> 자동 생성: `train/eval_traj_split.py` (P0-1) · 데이터 `dataset/trajectories/`
> seed 단위 split — train 84 / val 18 / test 18 scene · 관측 8(3.2s)/예측 12(4.8s)
> **val = 모델·운영점 선택 근거, test = 최종 1회.** CI = scene 단위 bootstrap 95% (B=2000).
> manifest: `dataset/trajectories/split_manifest.json` (재현: `python train/make_traj_split.py`)
> 라이브 제어 지평선 1.6s(4스텝) · 정지반경 R=3.1m. 선제 안전층이라 **recall 우선**.

## 읽는 법

- "지금 반경 **밖**의 사람이 1.6s 안에 반경 안으로 진입할지"를 미리 맞혔나. 반경 안은 반응형 몫이라 제외.
- **recall**=실제 진입 중 미리 잡은 비율(놓치면 충돌) · **precision**=경보 중 진짜 비율(낮으면 헛정지).
- **최빈**=최상위 단일 모드 · **전모드**=K모드 합집합(보수적, recall↑). 이 둘이 운영점 후보다.
- CI = scene 단위 bootstrap 95%. test 는 val 선택 고정 후 1회.
