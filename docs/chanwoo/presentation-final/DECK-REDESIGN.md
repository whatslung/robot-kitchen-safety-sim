## 2. 슬라이드별 설계

각 칸: **한 줄 메시지 / 문제→해결 연결 / 넣을 에셋 / 핵심 지표(도메인)**

### 기 · 문제

**S1 · 타이틀 (두괄식 · 히어로 = A안 + 화재감지 합성)**
- 메시지: "불은 번지기 전에, 사람은 부딪히기 전에 — 예측해서 먼저 대응합니다." (결론을 첫 화면에)
- 히어로(Figure Lab 생성): **한 급식실 장면에 두 축 동시** —
  - 전경(충돌 회피): 로봇 팔이 주전자 쪽으로 후퇴 · 작업자 안전 통과 · 안전링(초록 감속/주황 정지) + 청록 예측 경로 점선 → 칩 "예측 경로 정지링 진입 → 팔 후퇴".
  - 배경(화재 감지): 다른 화구 불꽃+연기에 빨간 박스 `fire 0.9x` → 칩 "화재 감지".
  - 톤: fig8f WITH-prediction 렌더 계열(무대 톤). 참고 에셋 `00-overview-pipeline/fig8f_collision_vs_avoidance_front@2x.png` 우측 패널.
- 지표 하단 띠(3축·도메인 명시): 🔥 화재 감지 **0.90**(REAL) · 🚶 사람 검출 **0.98**(REAL·실사 학습) · 🔮 위험진입 예측 **0.93**(SIM 통제). 사람 0.98은 상한값 → S11서 0.84→0.98로 해소(C안). 추적 0.988은 히어로서 빼고 S11로.
- ⚠️ 정직성: 대표 합성 컷(소개용)일 뿐 단일 평가 프레임 아님. 화재·사람은 별도 모델. 박스 라벨은 그럴듯한 값만, **이미지에 성과 지표 새기지 말 것**(지표는 하단 텍스트).

**S2 · 문제: 위험한 순간은 못 찍는다 (3의 법칙 — 3위험 카드 유지)**
- 문제 정의(3카드 = 데이터가 없는 3이유): 화재(**촬영 불가**) · 사고(**재현 불가**) · 충돌(**사용 불가**) → **학습 데이터 부재**.
- 오프닝 시각 안정 위해 3카드 유지. ※ 기존 p2의 **CASE 02 이미지만** 교통사고(주제 무관) → 주방/산업 사고로 교체.
- 연결: 지금은 반응형(센서 접촉 후 정지=늦음) → 우리는 선제형(예측해서 미리 물러섬).
- 에셋(전부 외부 실사 뉴스/CCTV — repo엔 실사 화재 낱장 없음, 합성 불꽃은 "못 찍는다"와 모순이라 금지): 화재=외부 실사 주방 화재 컷 · 사고=끼임/협착 사고 컷(교체) · 충돌=로봇 사망 뉴스(기존). 하단 반응형↔선제형 박스.

**S3 · 기성 기술이 막힌 두 곳 (2분할 유지 — 속도·인식)**
- 장벽 01(속도): 원격 대형 VLM **3.2초** vs 온디바이스 **0.1초** → 3.2초 뒤 판단은 5.1m 전 장면.
- 장벽 02(인식): 5m 나디르에서 기성 검출기 recall **0.175** = 10명 중 8명 놓침.
- 하단 브리지: "세 가지 답" ①온디바이스 ②4분할 ③**합성**(화재 예고) → S4로.
- ⚠️ 화재를 3번째 컬럼으로 넣지 않음(강한 2비주얼 쪼그라듦=과잉). 화재 장벽 본질="못 찍는다"는 S2, 기술적 0.31은 S5·S10.
- 에셋: 기존 p3 그대로 — 3.2초 vs 0.1초 가로 막대 + 천장 탑뷰 실사진+0.175. 하단 3-답 브리지.

### 승 · 해결 (방법)

**S4 · 3장벽 → 3해법 지도 (목차 역할, S3와 같은 순서)**
- 화재(촬영 불가·0.31) → **합성 데이터 + 증강**(S5·S6) / 사람(0.175) → **나디르 재학습+4분할**(S7) / 속도(3.2초) → **온디바이스+예측**(S8·S9)
- S3의 장벽 A·B·C가 여기 해법 A·B·C로 1:1. **화재는 S3·S4 양쪽에 등장**(사람·속도와 평행).
- 에셋: 3열 매핑 도식(장벽→해법 화살표). 배경/보조로 `00-overview-pipeline/fig11_methodology@2x.png` 또는 `fig1_pipeline@2x.png`.

**S5 · [화재] 불을 못 내니 합성으로 만든다**

- 설계 기준: 불꽃 렌더 품질 C0→C3 올려도 Δ−0.014 → "품질 말고 **다양성**"으로 방향.
- 에셋(핵심): 증강zip `01_ppt_ready/01_normal_4way.png` + `03_fire_mid_4way.png` (RGB·클래스마스크·인스턴스·깊이 4분할 = 자동라벨 증명) · `01-fire/fire-synthesis-comparison-codex.jpg` (C0 vs C3).

**S6 · [화재] 현장 CCTV는 더럽다 → 노이즈 9종 증강**
- 문제→해결: 저해상·압축·수증기로 깨끗한 학습은 현장에서 무너짐 → 노이즈 9종 학습 주입. 3종(steam·grayscale·erase)은 **일부러 안 가르치고 시험지로**.

- (결과 "김을 불로 착각 안 함"은 S10으로 넘긴다 — 여기선 방법만.)

**S7 · [사람] 천장뷰는 사람이 너무 작다 → 4분할·융합·추적 사다리**
- 문제→해결: 나디르 원본 recall 0.175 → ① 사분면 확대 재검출 → ② 호모그래피 월드융합(잔차 5cm, 0.4m 병합) → ③ ByteTrack 시간축. **나열 아니라 0.175를 끌어올린 한 줄 사다리.**

**S8 · [사람] 한 장엔 미래가 없다 → 다음 1.6초 3갈래 예측**

### 전 · 성과 (결과) — before/after 집중 구간

**S10 · 화재 결과: 합성만으론 부족 → 실사학습이 답**
- before/after 그래프: recall **23.7% → 89.9%**, precision **84.2% → 97.9%** (동일 grouped test).
- 보강: 불꽃 제거 ablation 0.81→0.005("불꽃을 본다"), 헛불 fpr 0.46→0.066(하드네거티브). 김(steam, held-out)에도 헛경보 낮음.
- 에셋: `01-fire/fire-before-after-claude.png` (무대톤) 또는 `-codex.png` (담백톤).
- 도메인 주의: 합성 in-domain 0.81은 **확인값**(성과 아님) — 실전은 실사 0.90.

**S11 · 검출 결과: 기성은 못 찾고, 우리는 찾는다 ★핵심**
- **before/after 객체검출 이미지**(요청 핵심): 기성 모델 = 사람 0명 박스 vs 우리 = 전원 박스.
  - 에셋: `02-person/person-boxes-sim-before-after-claude.png` (0명→13명) · `person-overhead-boxes-montage-codex.png` (실사 박스).
- **recall/precision before/after 그래프** — ★ S1 히어로 0.98의 정직한 해소(C안):
  - 모두 **동일 실사 test 137장**(held-out, 누수 0). 출처 `detection-eval.md §3`.
  - stock(기성품) R **0.175** → 우리 방식(제한 실사 500 + 합성 200) R **0.844** → 실사 전량(3,406장) R **0.980**(상한).
  - 메시지: "제한된 실사로도 0.84, 실사를 다 쓰면 0.98 — **합성은 부족한 실사를 소폭이지만 일관되게 보완**(real+sim > real-only 전 지표)."
  - 에셋: `02-person/person-overhead-before-after-codex.png` · `person-real-transfer-claude.png` (실사 전이 0.270→0.844) · 3단 막대(0.175→0.844→0.980).
- 추적 흡수: 배포 추적기 0.988 한 줄로 언급(별도 슬라이드 삭제).
- 도메인 주의: SIM 섬 val 0.871은 **확인값**(성과 아님). 실전은 **REAL** — 우리 방식 0.844 / 실사 전량 0.980. (부록 A2 3-way 상세)

**S12 · 예측 결과: 직선은 곡선 진입을 놓친다 → 57% → 93%**
- before/after 그래프: 위험진입 예측 recall CV **57.1% → 학습 92.9%** (FN 48→8).
- 트레이드 정당화: precision 0.955→0.671 감수 — "놓친 진입=충돌, 오탐=잠깐 감속"이라 recall 최우선.

## 3. 지표 정리 (지금 슬라이드마다 값이 달라 혼선) ⚠️

**반드시 정리해야 할 것 — ADE(예측 오차)가 3가지 평가조건이 섞여 값이 제각각이다.**

| 평가 조건 | ADE(Transformer) | ADE(CV) | 어디서 | 슬라이드 용도 |
|---|---|---|---|---|
| 인공 제어보행(학습분포 밖) | 0.207 | 0.298~0.372 | 구 p10 / claude 차트 | ❌ 절대값 오해 소지 — 본문서 빼기 |
