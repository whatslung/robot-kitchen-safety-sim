# 젠스파크 사람 축 수정 프롬프트 (기존 덱 수정용)

기존 Genspark 덱(p10~p19)을 수정. **바뀌는 슬라이드마다 아래 프롬프트를 넣기.**
이동/삭제는 프롬프트 아니라 손 조작(맨 아래).

---

## [p10 → S9] 사람 축 오프너
```
이 슬라이드를 이렇게 바꿔줘.
제목: 천장에서 찾고 → 잇고 → 예측하고 → 물러섭니다
부제: 사람 축이 푸는 세 가지 문제 · 전 과정 0.1초
좌측: 파이프라인 흐름도 유지 (검출 → 추적 → 예측 → 안전 → 로봇)
우측: 기존 3블록(PERCEPTION/PREDICTION/SAFETY) 설명을 지우고 '3문제 카드'로 교체 —
 ① 오버헤드 감지: 천장 5m에선 사람이 머리·어깨만 → 기성 모델이 못 찾음
 ② 사람 예측 어려움: 스테이션마다 꺾이는 곡선 동선 → 직선 예측은 놓침
 ③ 단순 정지의 한계: 계속 멈추면 작업이 끊김 → 예측해 미리 비켜야
하단의 도달 5.7m · ADE 0.207 숫자는 삭제.
```

## [p12 → S10] 검출 방법 (재학습 + 4뷰 융합)
```
이 슬라이드를 이렇게 바꿔줘.
제목: 천장 시점으로 다시 배우고, 나눠 겹쳐 봅니다
부제: 기성이 못 보는 천장뷰를 — 재학습 + 공간 분할·융합으로
상단에 '① 오버헤드 재학습: 천장 시점 데이터로 YOLO 재학습' 한 줄 추가.
중앙 3이미지 유지: 5m 나디르 원본(사람 작아 놓침) · 4구역 확대 재검출 · 멀티카메라 월드 융합 도식.
하단의 단계별 사다리 표(존 단일 0.831 ~ 배포 0.988)는 삭제(부록으로 이동).
STEP 5(LSTM/예측)는 빼고 검출·융합까지만.
```

## [신규 슬라이드 → S11] 검출 결과 ★
```
새 슬라이드 추가.
제목: 기성은 못 찾고, 우리는 찾습니다
부제: 같은 천장 영상, 기성 모델은 사람을 못 찾고 우리는 다 찾습니다
좌: 천장뷰 사람 검출 박스 before/after — 기성 모델(박스 0개) → 우리 모델(전원 박스)
우: recall 큰 막대 — 기성 0.175 → 우리 0.98 (실사)
하단 한 줄: 잠깐 놓쳐도 번호 유지 → 배포 추적기 recall 0.988
(이미지는 생성 후 실제 검출 박스 이미지로 교체 예정)
```

## [p15 → S14] 회피 원리 (6대 제거)
```
이 슬라이드를 이렇게 바꿔줘.
제목: 얼마나 미리 봐야 하나 — 도달 반경 5.7m
SSM 거리 예산만 유지: 도달 5.7m = 정지 3.1m + 사람 이동(1.6m/s × 1.6초). 로봇 중심 정지/감속 링 도식.
우측 '왜 6대' 커버리지(4대 vs 6대) 블록은 삭제(부록으로 이동).
```

## [p19 → S13] 예측 결과 (막대만)
```
이 슬라이드를 이렇게 바꿔줘.
제목: 위험 진입 예측 57% → 93%
좌측 막대그래프만 크게 유지: 등속(CV) 57% · 칼만 70% · 학습형(LSTM) 93% (놓친 진입 48→8명).
트레이드 한 줄: precision 0.96→0.67 감수 — 놓친 진입은 충돌, 오탐은 잠깐 감속.
우측 풀 파이프라인 표(ADE/FDE/진입 R·P)는 삭제(부록으로 이동).
```

## [p14 → S12] 예측 방법 — 거의 그대로 (수정 최소)
```
이 슬라이드는 유지. 제목만 확인: '한 장엔 미래가 없다 — 다음 1.6초를 3갈래로'.
좌 궤적 학습 샘플 · 우 예측기 인코더-디코더 구조도 유지.
```
