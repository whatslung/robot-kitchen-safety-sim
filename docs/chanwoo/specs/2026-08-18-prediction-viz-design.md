# 설계 — 칼만 예측 시각화 (σ 음영 + 조감 패널)

> 작성 2026-08-18 · chanwoo · 대상 파일 `sim.html` (전부 JS/브라우저)

## 목표

라이브 검출→추적으로 나오는 사람별 (x,z)에 **칼만 예측 + 불확실성(σ)을 눈으로 보이게** 한다.
`CCTV → 검출 → 추적 → (x,z) → 예측 → SSM` 사슬의 **예측 단계를 시각적으로 완성**해,
"사람 움직임을 예측해 로봇이 선제 감속" 데모를 한 화면에서 보여준다.

## 현재 상태 (이미 있는 것 — 변경 안 함)

- 칼만 필터 `PRED.kx/kz`, σ 계산(`PRED.sigma`, 지평선 끝 1σ[m]).
- 예측 경로 3D 선 `PRED.line` (위협도별 색).
- 정지/감속 링 `stopRing`·`slowRing` (SSM 동적).
- 소스 선택 `safetyUpdate`: `MIL.on`이면 위협 트랙(`milThreatSrc()`), 아니면 GT 최근접 사람.
- 선제 감속 판정 `PRED.tStop/tSlow`. 학습형 훅 `__customPredictor`.

## 빠진 것 = σ의 시각화 (이번 작업)

σ는 계산·판정엔 쓰이나 화면엔 예측선만 있고 **불확실성 음영이 없다**. 이걸 두 형태로 채운다.

## 범위 / 비목표 (YAGNI)

- 안전 판정용 예측은 **위협 트랙 1명** 그대로. 시각화에서 다른 사람은 **점으로만** 표시.
- 멀티 예측기·학습형 예측기 구현은 안 함(훅은 이미 있음).
- Python 변경 없음 — 검출/추적은 `backend/detect_server.py` 그대로. **예측·시각화는 전부 JS.**

## 아키텍처

- 전부 `sim.html`(브라우저). Python(detect_server)은 박스+id까지만.
- 데이터 소스: `MIL.on`이면 `MIL.tracks`의 월드 (x,z), 아니면 GT 최근접 사람 — 기존 배선 재사용.
- 좌표계: 월드 (x,z)[AU] ↔ 미터는 `SCALE.m()/SCALE.au()`. 로봇 기준 `LAYOUT.robot.base`.

## 컴포넌트 ① 2D 조감 패널 (canvas 오버레이) — 우선

- **위치/크기**: 화면 우하단 고정 오버레이(예 220×220px), 토글로 on/off. 기존 오버레이 캔버스(`drawOverlay` 경로) 안에 그리거나 전용 캔버스.
- **좌표 매핑**: 로봇을 패널 중심에, 반경 R_view(예 3.5m)를 패널 반폭에 매핑(미터→px 선형). 위=월드 +Z, 오른쪽=월드 +X(orthotop 계약과 동일).
- **그리는 것**:
  - 로봇 중심 마커 + 정지원(빨강)·감속원(노랑) — `SAFE.stopR/slowR`(m).
  - 추적된 사람들: `MIL.tracks` 각 id를 색 점(검출 색 팔레트와 일치).
  - 위협 트랙: 예측 경로 폴리라인(`PRED` 스텝 위치) + **σ 음영** — 지금(폭 0)에서 지평선(폭 ≈ σ)으로 벌어지는 반투명 부채꼴/타원. 색은 위협도(정상 초록/감속 노랑/정지 빨강).
  - 눈금: 1m 격자 또는 반경 라벨.
- **갱신**: 렌더 루프에서 `safetyUpdate` 뒤 1회. 없으면(트랙 없음) 링만.

## 컴포넌트 ② 3D 씬 σ 밴드

- 기존 `PRED.line` 스텝 점들을 따라 **반투명 밴드 메시**(ribbon)를 만든다. 폭 = `SCALE.au(σ) · (t/horizon)`(지평선으로 갈수록 벌어짐).
- 바닥 근처(y≈0.05) 평면 리본, alpha 낮게, 색은 위협도.
- `predictionUpdate` 끝에서 `PRED.line`과 함께 갱신·색 동기화. 이동 중일 때만 표시(`PRED.line`과 동일 조건).
- orthotop 등 모든 카메라뷰에서 보임.

## 데이터 흐름

```
MIL.tracks(x,z) ─┐
GT person       ─┴→ safetyUpdate → predictionUpdate(srcPos) → PRED.line, PRED.sigma, tStop/tSlow
                                    ├→ [②] 3D σ 밴드 메시 갱신
                                    └→ [①] 2D 조감 패널 draw (로봇·링·점·경로·σ 음영)
```

## 검증 (실측으로 확인)

1. `MIL.on` + 사람 이동 → 조감 패널에 점·예측경로·σ 음영이 뜨고, 움직이면 경로가 진행 방향을 가리킨다.
2. **σ가 지평선으로 갈수록 넓어진다**(now 폭≈0 → 끝 폭≈σ). 정지 상황이면 색이 빨강.
3. 가만히 서 있으면(속도<0.08㎧) 예측선·밴드 숨김(오탐 방지, 기존 규칙).
4. 트랙 없음/미검출 → 패널은 링만, 3D 밴드 숨김(예외로 안 죽음).
5. 3D 밴드가 orthotop 뷰에서 예측선을 감싸고 위협도 색과 일치.

## 토글/설정

- 조감 패널·3D 밴드 각각 on/off (기본 on). `__sim`에 노출해 콘솔에서도 제어.
- σ 표시 배율 등 상수는 `PRED`/패널 설정 객체에 모아둠.
