# 설계+계획 — 바닥 확률밀도 음영 (Trajectron++ 스타일 논문 그림)

> 2026-08-19 · chanwoo · 대상 `sim.html` (JS만) · 선행 [2026-08-18-prediction-viz-design.md](2026-08-18-prediction-viz-design.md)

## 목표

orthotop(수직 나디르)에서 보면 **논문 그림**이 되도록: 미래 위치 확률밀도를 **바닥에 부드러운 색 음영**으로 깔고, 예측 궤적을 **굵은 선**으로. 지금 σ 쐐기는 짧고 좁아 잘 안 보임 → **길고 넓게**.

## 핵심 결정

| 항목 | 값 | 이유 |
|---|---|---|
| 데이터 구조 | `PRED.mix` = `[{x,z,sx,sz,w}]` 가우시안 혼합 | 칼만=시점별 단일모드, 나중에 학습형(CVAE)이 GMM을 주면 **같은 렌더가 멀티모달 봉우리**를 그림 → Trajectron++ 비교 그림 공짜 |
| 그림 지평선 | `PRED.vizHorizon = 3.5s` (신설) | "길게". **안전 판정은 `PRED.horizon` 1.6s 그대로** — 행동 변화 없이 그림만 길게 |
| σ 하한 | `0.24` AU (사람 충돌 캡슐 반경 = 어깨 반폭) | "넓게, 사람 가로 면적만큼". t=0에서도 사람 폭만큼 보임 |
| 바닥 음영 | `DynamicTexture`(64×64) → 방 전체 덮는 평면, y=0.03 | 저해상도 + 이중선형 보간 = 부드러운 구름. 알파 ∝ 밀도, 색 = 위협도 |
| 굵은 선 | `CreateGreasedLine` (두께 지원) | 기본 `CreateLines`는 1px 고정이라 "라인 세게" 불가 |
| **데이터셋 오염 방지** | `gtOff()`에서 음영·굵은선·σ밴드 숨김, `gtOn()` 복원 | ⚠️ 필수. 음영이 사람을 따라다니므로 학습 데이터에 남으면 "바닥 색번짐→사람" 허위 상관 학습 |
| 성능 | 밀도 재계산 ~10Hz, 이동 중일 때만 | 64×64×성분수 → 매 프레임 불필요 |
| 범위(YAGNI) | 3D 바닥만. 2D 조감 패널은 기존 σ 쐐기 유지. σ밴드는 음영 켜지면 자동 off(토글 복귀 가능) | 중복 회피 |

## 밀도 수식

칼만 축별 공분산에서 미래 시각 t의 위치 분산:
```
var_a(t) = P00 + 2t·P01 + t²·P11 + σa²·t⁴/4      (a = x, z)
σ_a(t)   = max(sqrt(var_a(t)), 0.24)              ← 사람 반폭 하한
```
혼합 성분 = `vizSteps`개 시점(t = 0…vizHorizon), 각 `{x:px, z:pz, sx:σx(t), sz:σz(t), w:1}`.
밀도 `f(x,z) = Σ w_i·exp(-½[((x-xi)/sxi)² + ((z-zi)/szi)²])` (정규화 생략 — 표시는 최대값 기준 상대 알파).

## 작업 순서 (각 단계: 구현 → 브라우저 검증 → 커밋)

1. **`PRED.mix` 생성** — `vizHorizon`·`vizSteps`·σ하한 추가, `predictionUpdate`에서 혼합 채움. 검증: `__sim.PRED.mix` 길이·σ 단조증가·최소 0.24.
2. **바닥 음영 평면** — `DynamicTexture` 평면 생성 + 밀도 그리기(10Hz 스로틀), 위협도 색. 검증: 텍스처 픽셀에 알파>0 영역 존재, orthotop 캡처에 음영 보임.
3. **굵은 선** — `PRED.line`을 `CreateGreasedLine`으로 교체(두께 `PRED.lineW`). 검증: 메시 타입·화면에서 두께 확인.
4. **GT 숨김** — `gtOff/gtOn`에 음영·선·밴드 토글. 검증: `groundTruth('orthotop')` RGB에 음영 없음(캡처 대비), 복원 후 다시 보임.
5. **논문 그림 캡처 + 문서/핸드오프 갱신.**

## 검증 기준

- orthotop 뷰에서 사람 앞으로 **길고 넓은 부드러운 음영 + 굵은 선**이 보인다.
- 정지(속도<0.08㎧) 시 숨김, 이동 시 표시. 위협도에 따라 초록/노랑/빨강.
- **데이터셋 캡처 RGB에 음영·굵은선 없음** (학습 데이터 순수성).
- 안전 판정(정지/감속 시점)은 이번 변경으로 **바뀌지 않음** (viz 지평선 분리).
