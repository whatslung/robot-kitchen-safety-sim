급식 로봇 안전 시뮬레이터 — 사용법

천장 카메라로 사람·화재를 인식해 로봇을 선제 감속·정지시키는 안전 시스템을 시험하는 시뮬레이터입니다.

1분 안에 해보기

  • ▶ 자동 작업을 누르면 로봇이 튀김 바스켓을 건져 카트로 옮깁니다.
  • WASD로 조리원을 직접 걸어서 로봇에 다가가 보세요 — 가까워지면 노란 감속, 더 가까우면 빨간 정지가 걸립니다.
  • 왼쪽 STAGE 패널 아래 "시점" 목록을 누르면 그 카메라 화면으로 바뀝니다 (Shift+클릭 또는 우클릭 = 작은 화면으로).
  • 화면 우상단의 작은 화면(PiP)이 모델 입력 시점입니다. 클릭하면 다음 카메라로 넘어가고, 더블클릭하면 큰 화면과 자리를 바꿉니다.
  • 큰 화면을 바꿔도 작은 화면은 그대로입니다. 다만 고른 시점이 작은 화면에 떠 있던 것이면 둘이 자리를 맞바꿉니다(같은 그림이 두 번 나오지 않게).
  • 시점을 위로 올려 내려다보면 천장(후드·배관)이 저절로 사라집니다. 내려서 옆에서 보면 다시 나타납니다 — 따로 켤 필요 없습니다.

키보드

  • WASD 지금 고른 조작 대상을 움직입니다 · Shift 빠르게
  • Tab 조작 대상 전환 — 🎥 자유 시점(WASD 이동·QE 높이) ↔ 🚶 사람 ↔ 🤖 로봇 관절. 오른쪽 ▶ 실행 탭의 "조작 대상"에서도 고를 수 있습니다.
  • 로봇 모드: W/S 어깨 · Q/A 베이스 · E/D 팔꿈치 · R/F 손목 · T/G 회전
  • C 주 시점 캡처 · Shift+C 주 시점 + PiP 둘 다
  • 0 자유 시점 · 1~3 카메라 전환(그 외는 왼쪽 시점 목록) · P PiP 순환 · X PiP와 교환
  • Space 정지 · H 이 도움말
  • 마우스: 드래그 회전 · 휠 확대 · 우클릭 드래그 이동

탭 안내

  • ▶ 실행 — 로봇 조작, 조리 설정, 사람/화재/사고 시나리오
  • 📷 카메라 — 시점 프리셋, 카메라 추가·위치 조정, 캡처
  • 📊 데이터 — 학습용 이미지·라벨 자동 생성(Ground Truth), 모델 연결
  • ⚙ 고급 — 물리 엔진, 외부 3D 파일 불러오기

학습 데이터가 필요하면

  • 📷 카메라 탭에서 원하는 각도를 잡고 이 시점을 카메라로 등록 — 카메라는 몇 대든 늘릴 수 있습니다.
  • 📊 데이터 탭의 데이터셋 생성은 카메라마다 RGB·마스크·깊이·YOLO 라벨을 자동 저장합니다.

로봇 접촉 사고 검출 실패 조건
안전 정지가 정상 동작하면 접촉은 일어나지 않습니다(그게 맞는 동작입니다). 두 버튼은 모델이 사람을 못 본 상태를 강제해 로봇을 멈추지 않게 합니다 — 이 연구가 겨냥하는 실패 모드입니다.
